# 03 — 本机开发环境配置

> 适用场景：在本机 Windows 上搭建 Python 开发环境

## 1. 前置条件

| 项目 | 要求 |
|------|------|
| OS | Windows 10/11 |
| Python | 3.11+（推荐 3.11.5） |
| pip | 23.0+ |
| Git | 2.40+ |
| 虚拟机 | PG+Redis 已部署且可访问 |

验证 Python 版本：
```powershell
python --version
# 应输出: Python 3.11.5 或更高
```

## 2. 创建虚拟环境

```powershell
cd D:\PyProject\TableTennisAnalysis

# 创建虚拟环境
python -m venv .venv

# 激活
.venv\Scripts\Activate.ps1

# 验证
python --version
pip --version
```

如果 PowerShell 提示执行策略错误：
```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

## 3. 安装依赖

### 正常安装

```powershell
pip install -r requirements.txt
```

### SSL 证书问题兜底方案

如果遇到 `SSL: CERTIFICATE_VERIFY_FAILED` 错误：

```powershell
pip install -r requirements.txt `
    --trusted-host pypi.org `
    --trusted-host pypi.python.org `
    --trusted-host files.pythonhosted.org
```

> **注意**：`--trusted-host` 会跳过 SSL 验证，仅在开发环境使用。
> 生产环境应配置正确的 CA 证书。

### 安装 paramiko（远程部署用）

```powershell
pip install paramiko `
    --trusted-host pypi.org `
    --trusted-host pypi.python.org `
    --trusted-host files.pythonhosted.org
```

### 安装 asyncpg（连接测试用）

```powershell
pip install asyncpg `
    --trusted-host pypi.org `
    --trusted-host pypi.python.org `
    --trusted-host files.pythonhosted.org
```

## 4. 验证依赖安装

```powershell
python -c "import fastapi, uvicorn, sqlalchemy, alembic, redis, pydantic, httpx, pytest, slowapi, asyncpg, paramiko; print('All OK')"
```

## 5. 配置 .env 文件

### 创建 .env

```powershell
# 从模板复制
Copy-Item .env.example .env
```

### 修改关键配置

编辑 `.env`，将 `localhost` 改为虚拟机 IP：

```ini
# ---------- Database ----------
DATABASE_URL=postgresql+asyncpg://tta_user:tta_pass_dev@192.168.40.147:5432/tta

# ---------- Redis ----------
REDIS_HOST=192.168.40.147
REDIS_URL=redis://:redis_dev_pass@192.168.40.147:6379/0

# ---------- Celery ----------
CELERY_BROKER_URL=redis://:redis_dev_pass@192.168.40.147:6379/1
CELERY_RESULT_BACKEND=redis://:redis_dev_pass@192.168.40.147:6379/2
```

### 生成 JWT 密钥

```powershell
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

将输出的密钥填入 `.env` 的 `JWT_SECRET_KEY` 和 `JWT_REFRESH_SECRET_KEY`。

## 6. 配置 PYTHONPATH

PowerShell 中设置环境变量（每次新开终端需要设置）：

```powershell
$env:PYTHONPATH = "D:\PyProject\TableTennisAnalysis"
```

或者永久设置：
```powershell
[System.Environment]::SetEnvironmentVariable("PYTHONPATH", "D:\PyProject\TableTennisAnalysis", "User")
```
