# 01 — VM 环境准备

> 适用场景：新虚拟机初始化，从零搭建 Docker 运行环境

## 1. 虚拟机基础要求

| 项目 | 最低配置 | 推荐 |
|------|----------|------|
| CPU | 2 vCPU | 4 vCPU |
| 内存 | 2 GB | 4 GB |
| 磁盘 | 20 GB | 50 GB |
| OS | CentOS 7 / Ubuntu 22.04 | CentOS 7 |
| 网络 | NAT/桥接，可被本机访问 | 桥接，静态 IP |

## 2. 安装 Docker

### CentOS 7

```bash
# 安装依赖
sudo yum install -y yum-utils device-mapper-persistent-data lvm2

# 添加 Docker CE 仓库
sudo yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo

# 安装 Docker
sudo yum install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin

# 启动并设置开机自启
sudo systemctl start docker
sudo systemctl enable docker

# 将当前用户加入 docker 组（免 sudo）
sudo usermod -aG docker $USER

# 重新登录使组生效
exit
# 重新 SSH 登录

# 验证
docker --version
docker compose version
```

### Ubuntu 22.04

```bash
# 一键安装
curl -fsSL https://get.docker.com | sudo sh

# 加入 docker 组
sudo usermod -aG docker $USER

# 重新登录后验证
docker --version
docker compose version
```

## 3. 配置 SELinux（CentOS 7 必须）

CentOS 7 默认 SELinux 为 Enforcing 模式，会阻止 Docker 容器写入数据卷。
PostgreSQL 容器因此报错 `could not write to file "postmaster.pid": Operation not permitted`。

### 临时设置（重启后失效）

```bash
sudo setenforce 0
getenforce   # 应输出 Permissive
```

### 永久设置（重启后仍然生效）

```bash
sudo sed -i 's/^SELINUX=enforcing/SELINUX=permissive/' /etc/selinux/config
grep '^SELINUX=' /etc/selinux/config
# 应输出: SELINUX=permissive
```

> **注意**：即使 SELinux 设为 Permissive，PostgreSQL 容器仍需 `privileged: true` 才能正常写入数据卷。
> 这是 CentOS 7 + Docker overlay2 存储驱动的已知问题。

## 4. 防火墙配置

### CentOS 7 (firewalld)

```bash
# 检查 firewalld 状态
systemctl status firewalld

# 如果运行中，开放 PG 和 Redis 端口
sudo firewall-cmd --permanent --add-port=5432/tcp
sudo firewall-cmd --permanent --add-port=6379/tcp
sudo firewall-cmd --reload

# 或者直接关闭防火墙（仅开发环境）
sudo systemctl stop firewalld
sudo systemctl disable firewalld
```

### Ubuntu (ufw)

```bash
sudo ufw allow 5432/tcp
sudo ufw allow 6379/tcp
```

## 5. 磁盘与内存检查

```bash
# 磁盘空间
df -h /

# 内存
free -h

# Docker 磁盘占用
docker system df
```

## 6. 验证

```bash
# Docker 运行正常
docker run --rm hello-world

# Docker Compose 可用
docker compose version

# SELinux 状态（CentOS 7）
getenforce

# 端口未被占用
ss -tlnp | grep -E '5432|6379'
# 应无输出或显示端口空闲
```

## 7. SSH 访问确认

确保本机可以通过 SSH 连接虚拟机：

```bash
# 在本机执行（PowerShell）
ssh root@192.168.40.147
# 输入密码 123456
```

如果 SSH 连接失败，检查：
1. 虚拟机 IP 是否正确（`ip addr`）
2. 虚拟机是否已安装 `openssh-server`（`yum install -y openssh-server && systemctl start sshd`）
3. 防火墙是否放行 22 端口
