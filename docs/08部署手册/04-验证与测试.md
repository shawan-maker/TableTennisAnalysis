## 常见问题

### uvicorn 启动报 `ModuleNotFoundError`

**解决方案**：确认设置了 `PYTHONPATH`：
```powershell
$env:PYTHONPATH = "D:\PyProject\TableTennisAnalysis"
```

### Alembic 报 `UnicodeDecodeError: 'gbk' codec`

**根因**：alembic.ini 中有中文注释，Windows GBK 编码无法解析

**解决方案**：将 alembic.ini 中的中文注释改为英文

### pytest 报 `TypeError: Object of type datetime is not JSON serializable`

**根因**：response.py 中 `success()` 函数未处理 datetime 序列化

**解决方案**：确认 `app/core/response.py` 使用了 `jsonable_encoder`：
```python
from fastapi.encoders import jsonable_encoder
# ...
"data": jsonable_encoder(data),
```

### pytest 报 `assert 403 == 401`

**根因**：HTTPBearer 默认返回 403 而非 401

**解决方案**：确认 `app/core/deps.py` 中 `HTTPBearer(auto_error=False)` 且手动处理 `credentials is None`
