## 一、产品愿景与定位

### 1.1 一句话定义

**一套以 AI 驱动的乒乓球技战术数据分析为核心，集训练指导、社区交流、赛事服务、装备电商于一体的乒乓球垂直智能服务平台。**

### 1.2 与原始项目的关系

| 维度 | 原始项目（Eric个人） | 本产品（商业化） |
|---|---|---|
| 目标 | 升学作品集 | 商业化产品 |
| 用户 | Eric 一人 | 全国/全球乒乓球爱好者 |
| 技术栈 | Python + pandas + opencv（脚本级） | 全栈工程化（云+端+AI） |
| 分析深度 | 手工记录 + 基础统计 | AI 自动识别 + 专业级分析 |
| 教学方式 | 数据图表 + 文字 | 可视化视频模型 + 体系化训练方案 |
| 商业模式 | 无 | 多元变现（订阅 + 电商 + 服务） |

### 1.3 核心价值主张

> **"让每一位乒乓球爱好者，都能拥有专业教练级别的数据分析和训练指导。"**

目前市场上**没有**一款产品能同时做到：
- 自动分析比赛/训练视频，提取球速、落点、弧度、技术动作等专业数据
- 基于分析结果，生成体系化的改进方案（不是泛泛的文字建议）
- 对具体动作问题，提供可视化的视频模型教学（看到"正确动作"是什么样）
- 并围绕核心能力形成完整的乒乓球生态（约球、赛事、社区、电商）

## 二、市场分析

### 2.1 市场规模

- **中国乒乓球人口**：估算活跃爱好者 3000万+（乒协注册 + 民间爱好者），其中有一定训练需求和付费意愿的核心用户约 300–500 万
- **教练资源缺口**：专业乒乓球教练严重不足，尤其二三线城市和县城，大量爱好者"有热情没指导"
- **竞品现状**：
  - 开球网（kaiqiuwang.com）：赛事报名 + 积分排名，无技术分析能力
  - 乒乓球教学类 App/小程序：多为视频教程库，无个性化数据分析
  - 通用运动分析产品（如 Hudl）：面向团队球类，无乒乓专项
  - AI 运动分析（如 HomeCourt）：篮球/足球为主，未覆盖乒乓球
- **结论**：**乒乓球垂直智能分析赛道几乎空白，存在明显的蓝海窗口期**

### 2.2 市场机会窗口

- 乒乓球在国内有巨大群众基础但数字化程度极低
- AI 视频分析技术（目标检测、轨迹追踪、动作识别）近年快速成熟
- 运动爱好者为"提升水平"付费的意愿在增长（参考健身 App、高尔夫分析 App 的商业化路径）
- 国家体育数字化政策支持

## 四、核心能力深度分析：乒乓球数据分析师

> 这是整个产品的灵魂和护城河，需要单独深入分析。

### 4.1 能力分层

```
┌─────────────────────────────────────────────────────┐
│  L4: 体系化训练方案生成（AI 教练）                      │
│  → 基于分析结果，自动生成个性化训练计划                  │
├─────────────────────────────────────────────────────┤
│  L3: 可视化教学（动作模型）                            │
│  → 针对识别出的动作问题，提供3D/视频模型对比教学          │
├─────────────────────────────────────────────────────┤
│  L2: 专业级数据分析                                    │
│  → 球速、落点分布、弧度、技术动作识别、战术模式分析        │
├─────────────────────────────────────────────────────┤
│  L1: 数据采集与处理                                    │
│  → 视频采集（手机/相机）+ 手动数据录入                   │
└─────────────────────────────────────────────────────┘
```

### 4.2 L1 — 数据采集与处理

#### 4.2.1 视频数据采集

| 采集方式 | 说明 | 精度等级 |
|---|---|---|
| **手机单机拍摄** | 用户用手机录制比赛/训练视频上传 | 基础级（可分析技术动作、回合统计、落点区域） |
| **手机慢动作** | 240fps 慢动作视频 | 中等级（可分析击球动作细节、拍速估算） |
| **多角度拍摄** | 两个以上手机/相机同步拍摄 | 专业级（可做3D轨迹重建、精确球速/落点） |
| **固定摄像头** | 球馆部署固定摄像设备 | 持续监测级（自动记录每场训练） |

> **关键决策点**：MVP 阶段以"手机单机拍摄"为主入口，降低用户使用门槛。多角度和固定摄像头作为后续进阶能力。

#### 4.2.2 手动数据录入

- 比赛记分（每分得分方式、得分方、关键分标记）
- 落点区域标注（球台九宫格分区）
- 技术动作标记（发球类型、攻防转换、得分/失分原因）
- 自评状态（体能、手感、对手强弱）

> 保留手动录入路径非常重要：
> 1. 不是所有用户都有条件拍视频
> 2. 手动数据积累快，可快速建立用户粘性
> 3. 手动标注数据可用于训练 AI 模型

### 4.3 L2 — 专业级数据分析

#### 4.3.1 视频AI分析能力

| 分析维度 | 具体指标 | 技术难度 | 说明 |
|---|---|---|---|
| **球体检测与追踪** | 乒乓球轨迹 | ★★★★☆ | 乒乓球小（40mm）、快（业余可达 15–25 m/s），CV 检测难度大 |
| **球速估算** | 每板击球速度 | ★★★☆☆ | 基于帧间位移 + 已知帧率估算，需镜头标定 |
| **落点分析** | 球台落点分布热图 | ★★★☆☆ | 需要球台平面检测 + 落点坐标映射 |
| **弧度分析** | 球的飞行弧线 | ★★★★☆ | 需多帧轨迹拟合 + 弧线参数提取 |
| **技术动作识别** | 正手/反手/搓/拉/挑/发球等 | ★★★☆☆ | 基于人体姿态估计 + 动作分类模型 |
| **击球节奏** | 回合节奏、攻防转换频率 | ★★☆☆☆ | 基于击球事件检测 + 时间序列分析 |
| **站位与移动** | 选手场上覆盖范围 | ★★★☆☆ | 人体检测 + 轨迹追踪 |

#### 4.3.2 数据统计分析能力

- **技术占比分析**：正手/反手使用率、攻防比例、发球得分率
- **效率分析**：正手得分效率 vs 反手得分效率、关键分胜率
- **落点分布**：自己落点热图 + 对手落点热图（攻防策略分析）
- **趋势分析**：跨比赛的技术变化曲线、积分/水平变化关联
- **对手建模**：主要对手的习惯落点、发球偏好、弱点区域

#### 4.3.3 关键技术挑战（需重点评估）

> **乒乓球视频分析是整个项目最大的技术风险点**，原因：

1. **球体小且快**：乒乓球直径仅 40mm，业余选手击球速度可达 15–25 m/s，专业选手可达 25–35 m/s。在普通手机 30fps 视频中，球在两帧间可能移动 0.5–1.2 米，容易出现"丢球"
2. **单目相机局限**：单台手机无法精确定位 3D 空间中的球和落点，需要镜头标定 + 球台参考系建立
3. **球场环境复杂**：光线变化、球台反光、多人场景、观众干扰
4. **缺乏公开数据集**：乒乓球 CV 领域没有大规模标注数据集，需要自建

> **建议策略**（已确认：全自动路线）：
> - 流程上全自动：用户上传视频 → 系统自动分析 → 自动生成报告，用户无需逐帧确认
> - 精度上分阶段提升：初期覆盖核心指标（回合统计、落点区域、动作大类），逐步提升到专业级精度（球速、弧度、动作细节）
> - 数据飞轮：用户反馈（分析对/不对）→ 标注数据积累 → 模型 fine-tune → 精度持续提升
> - 长期：多角度拍摄支持下的专业级分析

### 4.4 L3 — 可视化教学（动作模型）

#### 4.4.1 教学内容体系

| 教学形式 | 实现方式 | 适用场景 |
|---|---|---|
| **3D 数字人物动作模型** | 用原创 AI 数字人物模型演示标准动作，3D 引擎渲染，可旋转、慢放、逐帧查看 | 技术动作教学（拉球、搓球、发球等） |
| **对比分析** | 用户视频 vs 3D 标准动作的并排/叠加对比 | 动作纠错（如"你的正手拉球引拍幅度过大"） |
| **标注教学内容** | 技术要点文字 + 关键帧标注，关联 3D 模型 | 技战术学习 |
| **分解训练指导** | 每个技术动作的分解训练步骤，配套 3D 模型跟练 | 跟练 |

> **版权安全设计**：3D 教学内容全部使用原创 AI 数字人物模型，不使用任何真人形象、真人教学视频或特定运动员动捕数据，彻底规避肖像权和著作权风险。

#### 4.4.2 内容生产路径

- **初期（Phase 0–2）**：创建原创 rigged 3D 数字人物模型，用关键帧动画制作核心技术动作（正手拉球/攻球、反手拉/拨、搓球、发球、步法等），通过 3D 引擎（Three.js / Unity）渲染为可交互教学
- **中期（Phase 2+）**：扩展动作库覆盖更多技术变体；引入通用运动参数驱动，半自动生成新动作
- **长期（Phase 5）**：AI 动作生成，基于动作参数描述自动生成 3D 动画，快速扩展教学库

> **专业知识来源**：技术标准、训练方法、动作要领的定义，从公开的专业教学内容（如张指导乒乓等内容创作者）中系统搜集整理，转化为结构化知识库。不依赖线下教练访谈，但保持与专业内容的一致性。

### 4.5 L4 — 体系化训练方案生成

#### 4.5.1 训练方案框架

```
分析报告（你的问题）
    ↓
诊断结论（核心短板 + 次要短板）
    ↓
训练目标（量化目标，如"正手拉球得分率从 40% 提升到 55%"）
    ↓
训练计划
    ├── 技术训练（具体动作练习方案 + 配套教学视频）
    ├── 战术训练（针对弱点的战术演练）
    ├── 体能训练（专项体能建议）
    └── 实战检验（定期比赛 + 复盘分析）
    ↓
进度追踪（下次分析对比改进效果）
    ↓
方案调整（动态优化训练重点）
```

#### 4.5.2 训练方案内容要求

- **不是泛泛的文字建议**（如"多练正手"），而是具体到：
  - 练什么动作（精确到技术名称和变体）
  - 怎么练（分解步骤 + 训练方法 + 配套视频）
  - 练多少（训练量、组数、频率）
  - 怎么验证（检验标准、自测方法）
  - 多久见效（预期改进周期）
- **可执行的训练单**：每次训练的具体内容清单，可打印/跟随

### 5.5 学习视频平台（Phase 3）

| 功能 | 说明 |
|---|---|
| 嵌入模式 | 聚合公开教学视频，引用原平台播放器嵌入（不下载不重新托管，无版权风险，零存储成本） |
| 授权本地化 | 与优质创作者达成授权，本地化存储视频（创作者授权+收益分成），统一播放器体验（慢放/逐帧/离线） |
| UGC 内容上传 | 用户/教练上传原创教学视频，创作者自主定价（免费或付费） |
| 平台抽成 | 创作者付费内容平台抽成 10–20%，平台不直接收费教学内容 |
| 视频分类 | 按技术类型（发球/正手/反手/步法/战术）、难度等级分类 |
| 跟练模式 | 视频慢放、循环、逐帧查看，辅助练习（仅授权本地化和UGC内容支持） |
| 与分析联动 | 基于用户分析报告，智能推荐相关教学视频 |
| 进度记录 | 学习记录、已掌握/待练习标记 |

> **商业模式**：平台作为内容发现和交易撮合平台。三种内容来源分层处理：嵌入模式（公开内容引流，免费）→ 授权本地化（提升体验，创作者分成）→ UGC 上传（创作者经济，平台抽成 10–20%）。
>
> **版权策略**：不直接下载他人视频。本地化存储仅限于有授权的创作者内容和用户原创上传。嵌入模式引用原平台播放器，规避版权风险。与 Phase 2 的 3D 数字人物教学互补：3D 模型教标准动作（平台自有），创作者视频教实战经验（UGC/授权）。

| 装备对比 | 多款装备参数对比 |

## 六、非功能性需求

### 6.1 性能需求

| 指标 | 要求 |
|---|---|
| 视频上传 | 支持上传 500MB 以内视频，上传成功率 >99% |
| 视频分析 | 单场视频（5分钟）AI 分析完成时间 <3 分钟（异步处理） |
| 页面加载 | 主要页面首屏加载 <2 秒 |
| 并发支持 | 初期支持 1000 并发用户，可水平扩展 |
| 记分牌 | 实时记分操作响应 <200ms |

### 6.2 可用性需求

- 系统可用性 ≥ 99.5%（初期）
- 视频分析服务支持队列处理，高峰期排队不丢失任务
- 核心功能（记分牌、约球）离线可用，网络恢复后同步

### 6.3 安全与隐私

- 用户视频数据加密存储，不未经授权用于其他用途
- 用户位置信息脱敏处理
- 符合个人信息保护法（PIPL）要求
- 未成年人保护机制（青少年用户需家长授权）

### 6.4 兼容性

- 移动端：iOS 14+ / Android 8+
- Web 端：主流浏览器（Chrome/Safari/Edge/Firefox）
- 微信小程序（考虑作为中国市场的轻量入口）

### 6.5 可扩展性

- 微服务架构，各功能模块可独立部署和扩展
- AI 分析服务可独立扩缩容
- 支持后续接入更多第三方服务（开球网、高德地图、支付等）

## 七、分阶段路线图

### Phase 1：基础版 MVP（3–4 个月）

> **目标**：验证核心价值，建立最小可用产品

**核心功能**：
- 用户注册/登录，个人档案（开球网积分、自评水平、打法类型）
- 手动比赛数据录入 + 数据看板（胜率曲线、技术占比、落点热图）
- 智能记分牌（实时记分 + 得分方式标记）
- 基础训练计划模板（基于数据分析结果的文字建议）

**不包含**：视频 AI 分析、3D 模型教学、学习视频库、约球、赛事、社区、电商

**验证目标**：用户是否愿意持续记录数据？数据看板是否有价值？

---

### Phase 2：视频分析 MVP（6–8 个月）

> **目标**：上线核心差异化能力 — 视频AI分析

**核心功能**：
- 视频上传与处理
- AI 全自动分析（球体检测追踪 + 落点区域 + 技术动作识别，用户无需逐帧确认）
- 核心指标：回合统计、击球频率、落点区域分布、技术动作识别（正手/反手等）
- 分析报告自动生成（文字 + 数据图表）
- 基于分析结果的训练建议（文字 + 推荐教学视频）
- 用户视频与标准动作的对比分析

**验证目标**：视频分析结果的准确度用户是否认可？用户是否愿意为分析付费？

---

### Phase 3：智能教练 + 社区（4–6 个月）

> **目标**：从"分析"升级为"教练"，并启动社区生态

**核心功能**：
- 3D 数字人物动作模型教学库（核心技术动作的原创 3D 数字人物模型，可交互）
- 体系化训练方案自动生成（L4 能力）
- 训练进度追踪与方案动态调整
- 社区交流（帖子、分享分析报告、技术问答）
- 同城约球 v1（LBS + 约球发布 + 水平匹配）
- 学习视频平台（公开内容聚合 + UGC 上传 + 创作者定价 + 平台抽成）
- 高级分析（对手建模、训练负荷分析、趋势预测）

**验证目标**：训练方案是否真的帮用户提升？社区活跃度？用户留存率？

---

### Phase 4：商业生态闭环（3–4 个月）

> **目标**：完成商业化闭环，多元变现

**核心功能**：
- 赛事报名与管理（含开球网对接）
- 地图导航集成（高德/百度）
- 装备评测与电商（评分 + 推荐 + 购买）
- 教练/俱乐部入驻与线上服务
- 会员体系完善（免费/付费分级）
- 数据增值服务（高级报告、定制分析）

**验证目标**：付费转化率？电商 GMV？教练服务交易量？

---

### Phase 5：专业化与规模化（持续迭代）

- 多角度视频分析（专业级球速/落点/弧度精度）
- 球馆固定摄像头方案（B端俱乐部服务）
- AI 动作生成（个性化对比教学）
- 联赛管理系统（B端赛事运营）
- 国际化（英文版，对接 USATT 等）

## 八、商业模式

### 8.1 收入模型

| 收入来源 | 模式 | 预期占比 | 启动阶段 |

| **广告** | 品牌广告（球拍品牌、赛事赞助） | 5% | Phase 3 起 |

### 8.2 会员分级（建议）

| 等级 | 价格 | 核心权益 |
|---|---|---|
| 免费版 | 0 | 手动数据录入 + 基础看板 + 记分牌 + 社区浏览 |
| 会员版 | 39 元/月 或 299 元/年 | 每月 3 次视频分析 + 训练方案 + 教学视频库 + 社区发帖 |
| 专业版 | 99 元/月 或 799 元/年 | 无限视频分析 + 3D 模型教学 + 高级报告 + 对手建模 |

> **关键策略**：免费版足够好用（手动数据 + 记分牌 + 社区），让用户留下来；视频分析和训练方案是付费的核心驱动力。

## 九、技术风险与应对

| 风险 | 等级 | 影响 | 应对策略 |
|---|---|---|---|
| 乒乓球视频AI分析精度不达预期 | ★★★★★ | 核心能力受损 | 全自动流程，精度分阶段提升；积累用户反馈标注数据逐步提升模型 |

## 十、已确认的关键决策

> 以下问题已在需求讨论中确认，记录如下：

### Q1：目标市场 → **中国市场为主**
- 微信生态优先，对接开球网/高德地图/微信支付

### Q2：视频分析技术路线 → **全自动**
- 流程全自动（用户上传→自动分析→自动报告），精度分阶段提升
- 数据飞轮：用户反馈→标注数据→模型优化

### Q3：专业知识来源 → **在线搜集汇总**
- 从公开专业教学内容（张指导乒乓等）系统搜集整理
- 转化为结构化知识库，不依赖线下教练访谈

### Q4：团队与资源 → **个人开发 + AI 辅助**
- 架构极简化，最大化云服务，最小化运维

### Q5：平台优先级 → **小程序 + App 同步**
- 跨平台框架统一开发

### Q6：MVP 验证 → **综合验证**
- Phase 1 覆盖数据 + 视频 + 付费完整闭环

### Q7：与开球网的关系 → **延用 + 对接**
- 不建独立积分体系，延用开球网积分（用户填写/后续 API 同步）
- 赛事系统后续对接开球网
