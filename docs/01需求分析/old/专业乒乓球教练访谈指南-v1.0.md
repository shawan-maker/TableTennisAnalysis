# 专业乒乓球教练访谈指南

> **目的**：通过结构化访谈，从专业教练处获取构建"乒乓球智能分析平台"所需的专业领域知识
> **使用方式**：打印本指南，按顺序与教练面谈（建议分 2–3 次，每次 1–1.5 小时）
> **访谈对象**：专业乒乓球教练（有竞技/教学经验）
> **预期产出**：技术动作体系、评估标准、训练方法论、数据分析维度定义

---

## 访谈前置说明（给教练看）

> 我正在开发一款乒乓球智能分析产品，核心功能是用 AI 分析比赛/训练视频，自动提取球速、落点、技术动作等数据，并给出专业级的改进建议和训练方案。
>
> 您的专业知识是产品的核心基础。以下访谈内容将帮助我们：
> 1. 定义"什么是正确的技术动作"（让 AI 知道标准是什么）
> 2. 定义"常见问题和改进方法"（让系统能给出有用建议）
> 3. 定义"如何评估一个球员"（让系统知道该看什么数据）
> 4. 定义"训练方案该怎么设计"（让系统能生成可执行的训练计划）
>
> 访谈内容可能涉及较细的技术讨论，请尽量具体、用案例说明。

---

## 第一部分：教练背景与教学经验（15分钟）

> 目的：了解教练的专业背景，校准后续讨论的深度和视角

1. **请介绍您的乒乓球背景**
   - 运动经历（运动员级别、最好成绩）
   - 教练经历（执教年限、执教对象水平范围、是否有教练证书/等级）
   - 目前主要教学场景（俱乐部/学校/专业队/个人培训）

2. **您日常教学中，最常接触到什么水平的学员？**
   - 初学/入门（刚开始打球）
   - 业余中级（能打比赛，有基本技术）
   - 业余高级/竞技级（参加比赛，有积分/排名）
   - 专业/半专业

3. **您目前如何评估一个学员的技术水平？**
   - 观察哪些方面？
   - 用什么标准判断"这个人的正手不行"或"反手是短板"？
   - 是否有量化的评估方法？

---

## 第二部分：技术动作体系（30分钟）⭐核心

> 目的：建立完整的技术动作分类体系，这是 AI 动作识别和教学的基础

### 2.1 技术动作全景

4. **乒乓球的核心技术动作有哪些？请尽可能完整地列出**
   - 提示：发球类、接发球类、正手类、反手类、步法类、战术组合类
   - 每个大类下面有哪些细分动作？
   - （请教练口述或手写一张技术动作树状图）

5. **对于以下每个核心技术动作，请详细说明：**

   > 对每个动作，我们需要了解：

   | 维度 | 问题 |
   |---|---|
   | 动作定义 | 这个动作的标准定义是什么？什么情况下使用？ |
   | 关键要点 | 执行这个动作时，身体各部位（脚/腿/腰/肩/手臂/手腕）的正确状态是什么？ |
   | 击球要点 | 击球点（上升期/高点期/下降期）、击球部位（球的中上部/中部等）、拍形角度 |
   | 常见错误 | 学员最常犯的错误是什么？错误的表现是什么？ |
   | 纠正方法 | 发现错误后，您通常用什么方法纠正？用什么训练手段？ |
   - 请重点讲解以下动作：
     - 正手攻球 / 正手拉球（弧圈球）
     - 反手拨球 / 反手拉球
     - 搓球（正手搓/反手搓）
     - 推挡 / 反手推
     - 发球（正手发球/反手发球，下旋/上旋/侧旋/不转）
     - 接发球（摆短/劈长/拧拉/挑打）
     - 步法（并步/交叉步/小碎步）

6. **不同水平阶段，技术重点分别是什么？**
   - 入门阶段最该练什么？
   - 中级阶段最该提升什么？
   - 高级阶段的关键技术是什么？
   - 每个阶段常见的"瓶颈"是什么？

### 2.2 技术动作的量化参数

7. **如果要用数据来描述一个技术动作的执行质量，您觉得哪些参数最重要？**
   - 例如：引拍幅度、挥拍速度、击球点高度、击球时机、拍面角度、身体重心位置……
   - 这些参数在专业级别和业余级别，典型数值范围大概是多少？

8. **球速、落点、旋转这三个核心维度，您的理解是：**
   - 业余选手（中级）和专业选手的球速差距大概多大？
   - 落点控制精度上，业余和专业差多少？（比如能不能控制到球台某个 20cm×20cm 的区域）
   - 旋转强度如何感知和衡量？

## 第三部分：比赛数据分析维度（25分钟）⭐核心

> 目的：定义"分析一场比赛时，该提取哪些数据、看哪些维度"

9. **您分析一场比赛（看录像）时，重点关注什么？**
   - 您的眼睛会追踪什么？（球的轨迹？选手的站位？击球动作？战术选择？）
   - 您如何在几分钟内判断一个选手的主要问题？

10. **以下数据维度，请评估对分析的重要程度，并补充遗漏的：**

    | 数据维度 | 重要程度（1-5） | 您的关注点 |
    |---|---|---|
    | 每板球速 | ? | |
    | 落点分布（自己的/对手的） | ? | |
    | 技术动作使用频率（正手/反手/搓/拉占比） | ? | |
    | 得分方式分布（发球得分/进攻得分/对方失误） | ? | |
    | 关键分表现（9:9后等） | ? | |
    | 击球节奏/回合长度 | ? | |
    | 站位与移动范围 | ? | |
    | 发球类型与得分率 | ? | |
    | 第三板/第五板得分率 | ? | |
    | 攻防转换频率 | ? | |
    | 失误类型与频率 | ? | |
    | （补充） | ? | |

11. **您认为哪些数据组合能反映一个选手的"打法风格"？**
    - 例如：正手使用率 >70% + 进攻得分率 >50% → 正手进攻型打法
    - 请描述几种典型打法类型及其数据特征

12. **对手分析：您赛前会如何分析对手？**
    - 关注对手的哪些习惯？（发球偏好、习惯落点、弱点区域、关键分处理）
    - 如何用数据描述一个对手的"打法档案"？

## 第四部分：常见问题与训练方法（30分钟）⭐核心

> 目的：构建"问题→诊断→训练方案"的知识库，这是 AI 教练功能的基础

13. **业余爱好者（中级水平，开球网 1200–1800）最常见的 5–10 个技术问题是什么？**
    - 对每个问题，请说明：
      - 问题表现：在外行看来是什么样的？（如何从视频中识别）
      - 根本原因：为什么会出现这个问题？
      - 影响后果：这个问题导致什么结果？（失分方式、上限限制）
      - 纠正方法：具体怎么练才能改？
      - 训练手段：用什么具体训练方法/练习形式？
      - 预期周期：大概练多久能改善？

14. **请描述一个完整的"训练方案"是什么样的？**
    - 您给学员制定训练计划时，包含哪些要素？
    - 一堂训练课的结构是怎样的？（热身 → 技术练习 → 战术练习 → 体能 → 放松？）
    - 一个周期（如4周）的训练计划如何设计？
    - 如何根据学员的具体问题调整训练重点？

15. **训练效果的检验标准**
    - 您如何判断一个训练方案是否有效？
    - 学员进步的标志是什么？（数据变化？比赛成绩？动作改善？）
    - 多久评估一次？用什么方法评估？

16. **您是否有现成的训练教案/训练计划模板可以分享？**
    - 如果有，请提供示例
    - 不同水平/不同问题的训练计划有什么区别？

---

## 第五部分：视频分析视角（15分钟）

> 目的：了解从视频角度可以观察到的信息，指导 AI 视频分析功能的优先级

17. **如果只能用一个固定角度的手机拍摄比赛视频，您建议什么角度？**
    - 正面/侧面/斜后方/俯拍？
    - 这个角度能看到什么、看不到什么？
    - 如果可以加第二个角度，您建议加在哪里？

18. **从普通手机视频（30fps）中，您能看出哪些技术问题？**
    - 哪些问题一眼就能看出来？
    - 哪些需要慢动作才能看清？
    - 哪些从视频里基本看不出来，需要现场才能判断？

19. **如果有一个 AI 系统能从视频中自动提取以下信息，哪些对您最有用？**
    - 请按优先级排序
    - 是否有您认为"AI 很难做到"但"教练一眼就能看出"的东西？

20. **您看过哪些乒乓球教学视频/分析视频？**
    - 您觉得好的教学视频是什么样的？
    - 哪些不好的教学视频，问题在哪？

---

## 第六部分：可视化教学需求（10分钟）

> 目的：了解"可视化视频模型教学"应该做成什么样

21. **如果系统要展示"标准动作"供学员模仿，您觉得什么形式最好？**
    - 专业运动员的实拍视频（多角度慢放）？
    - 3D 动画模型（可旋转、可逐帧）？
    - 动作分解图示（关键帧 + 标注）？
    - 还是其他形式？

22. **对于"对比分析"（用户视频 vs 标准动作），您觉得应该对比哪些方面？**
    - 如何在视觉上呈现"你的动作和标准动作的差异"？
    - 需要标注哪些关键点？（关节角度、拍面角度、重心位置等）

23. **您是否愿意参与录制标准动作教学视频？**
    - 如果愿意，可以提供哪些动作的教学？
    - 对录制条件有什么要求？

## 第七部分：产品反馈与建议（10分钟）

24. **您对我们这个产品概念怎么看？**
    - 您觉得对业余爱好者有价值吗？
    - 您觉得对教练有价值吗？
    - 您觉得用户会愿意付费吗？多少钱合理？

25. **您觉得这个产品最该先做什么功能？**
    - 如果只能先做一个功能，您建议做什么？

26. **您是否愿意成为产品的首批试用用户/顾问？**
    - 可以在开发过程中提供专业反馈吗？
    - 是否可以引荐其他教练/运动员参与？
