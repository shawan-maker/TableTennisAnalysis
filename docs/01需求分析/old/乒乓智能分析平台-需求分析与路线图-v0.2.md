## 修订后的分阶段路线图

### Phase 0：技术预研与知识储备（1–2 个月）

> **目标**：验证核心技术可行性，建立专业知识库

**并行任务**：

**A. 专业知识建设**
- 执行教练访谈（使用已输出的访谈指南）
- 整理技术动作体系、训练方法知识库
- 定义数据分析维度优先级
- 产出：专业知识库 v1（结构化文档）

**B. AI 视频分析技术验证**⭐最关键
- 乒乓球检测与追踪原型（用 YOLO/DeepSORT 等，验证能否从视频中检测到球）
- 球台检测与参考系建立（从画面中识别球台，建立坐标映射）
- 落点估算原型（基于球轨迹 + 球台平面，估算落点区域）
- 动作识别原型（用 MediaPipe 人体姿态估计 + 简单分类器，验证能否区分正手/反手）
- 产出：技术可行性验证报告 + 原型 Demo

**C. 技术架构设计**
- 跨平台框架选型（Taro vs uni-app vs Flutter+小程序）
- 云服务选型（AI 推理服务、对象存储、数据库、CDN）
- 系统架构设计（详见后续架构设计文档）

> **Phase 0 的核心判断点**：视频 AI 分析的原型效果如何？如果球体检测成功率 >70%、落点估算准确率 >60%，则技术路线可行，进入 Phase 1；如果效果太差，需要调整策略（如降低自动化预期、引入多角度方案等）。

### Phase 1：核心 MVP（4–6 个月）

> **目标**：上线完整的核心闭环（数据→视频分析→报告→训练建议→付费），综合验证产品价值

**功能模块**：

#### 模块 1：用户系统
- 微信登录（小程序）/手机号登录（App）
- 个人档案：水平自评、积分记录、打法类型
- 用户等级与积分体系

#### 模块 2：视频分析核心⭐
- 视频上传（手机拍摄引导：角度建议、时长限制）
- AI 自动分析（异步处理，后台排队）
  - 球体检测与轨迹追踪
  - 落点区域分布（九宫格热图）
  - 技术动作识别（正手/反手/发球等大类）
  - 回合统计（回合长度、击球频率、攻防转换）
  - 得分分析（如果可识别比分）
- 分析报告自动生成
  - 数据可视化图表（落点热图、技术占比、节奏曲线）
  - 文字分析结论（基于规则引擎 + 专业知识库）
  - 改进建议（关联训练方法 + 教学视频推荐）
- 分析结果反馈机制（用户标记"这个分析对/不对"，数据回流用于模型优化）

#### 模块 3：手动数据与记分牌
- 智能记分牌（实时记分 + 得分方式标记 → 自动生成比赛数据）
- 比赛数据手动录入（快速录入模板）
- 数据看板（胜率曲线、技术占比、落点热图、趋势分析）

#### 模块 4：训练建议与教学
- 基于分析报告的训练建议（文字 + 推荐教学视频）
- 训练计划模板（按问题类型推荐训练方案）
- 学习视频库 v1（分类浏览 + 跟练模式：慢放/循环/逐帧）

#### 模块 5：付费闭环
- 免费版：手动数据 + 记分牌 + 基础看板 + 社区浏览
- 付费版：视频分析（按次或包月）+ 训练方案 + 教学视频库
- 微信支付集成

**技术实现**：
- 跨平台 App（小程序 + App 一套代码）
- 云原生后端（Serverless / BaaS）
- AI 推理服务（云 GPU，按需调用）
- 视频处理流水线（上传 → 转码 → AI 分析 → 报告生成）

**验证指标**：
| 指标 | 目标 |
|---|---|
| 注册用户 | 1000+ |
| 视频分析使用次数 | 500+ |
| 分析准确度用户满意度 | >70% |
| 付费转化率 | >5% |
| 次日留存率 | >30% |

### Phase 2：智能教练升级（4–6 个月）

> **目标**：从"数据分析"升级为"AI 教练"，训练方案体系化

**功能模块**：

#### 模块 1：高级视频分析
- 球速估算（基于帧间位移 + 镜头标定）
- 击球动作细节分析（引拍幅度、挥拍轨迹、击球点）
- 弧度分析（球飞行弧线参数提取）
- 对手分析（对手落点偏好、发球类型统计）

#### 模块 2：3D 可视化教学
- 3D 动作模型库（核心技术动作的 3D 模型，可旋转/慢放/逐帧）
- 用户视频 vs 标准动作的对比分析（并排/叠加展示）
- 动作关键点标注（关节角度、拍面角度、重心位置）

#### 模块 3：体系化训练方案
- 自动诊断核心短板（基于分析数据 + 专业知识库规则）
- 生成个性化训练计划（目标→训练内容→训练量→检验标准→周期）
- 训练进度追踪（定期分析对比，方案动态调整）
- 训练单生成（每次训练的具体内容清单，可跟随执行）

#### 模块 4：深度数据分析
- 对手建模（习惯落点、发球偏好、弱点区域 → 一页 scout report）
- 训练负荷分析（训练量与水平变化关联）
- 趋势预测（基于历史数据预测水平变化趋势）
- 跨比赛对比分析

## 修订后的技术方向概要

> 详细的架构设计将在下一阶段输出，此处先确定方向。

### 跨平台方案对比

| 方案 | 优势 | 劣势 | 适配度 |
|---|---|---|---|
| **Taro 4（React 语法）** | 一套代码 → 小程序+H5+App(RN)，React 生态，社区活跃 | App 端 RN 体验不如原生，复杂动画性能一般 | ★★★★☆ |
| **uni-app（Vue 语法）** | 一套代码 → 小程序+H5+App，Vue 生态，DCloud 云打包 | App 端体验中等，深度定制受限 | ★★★★☆ |
| **Flutter + 小程序双栈** | Flutter App 体验最好，小程序原生开发 | 两套代码维护，工作量大 | ★★★☆☆ |
| **Flutter + Taro 组合** | App 体验最佳 + 小程序一套代码 | 两种技术栈，学习成本高 | ★★★☆☆ |

> **倾向建议**：Taro 4 或 uni-app（个人开发+AI辅助场景，一套代码极重要）。后续架构设计中详细对比后确定。

### 后端架构方向

- **云原生 + Serverless**：最大化减少运维，适合个人开发
- **微信云开发**（小程序端）+ **独立云服务**（App端 + AI 推理）
- **AI 推理**：云端 GPU 按需调用（阿里云/腾讯云 ECS GPU 或 Serverless GPU）
- **视频处理**：云端流水线（上传 → 存储 → AI 分析 → 报告 → CDN 分发）
- **数据库**：云托管数据库（MongoDB / PostgreSQL）
- **对象存储**：阿里云 OSS / 腾讯云 COS（视频和图片存储）

### AI 技术栈方向

| 能力 | 技术方案 |
|---|---|
| 球体检测 | YOLO 系列（YOLOv8/v11）fine-tune 乒乓球检测 |
| 球体追踪 | DeepSORT / ByteTrack（多目标追踪） |
| 球台检测 | YOLO + 关键点检测（球台四角定位） |
| 落点估算 | 轨迹预测 + 球台平面单应性矩阵映射 |
| 人体姿态 | MediaPipe / MMPose（人体关键点检测） |
| 动作识别 | 姿态时序序列 + LSTM/Transformer 分类 |
| 球速估算 | 帧间位移 + 帧率 + 镜头标定 |
| 报告生成 | 规则引擎 + LLM（大模型生成自然语言分析） |

> **数据飞轮设计**：用户上传视频 → AI 分析 → 用户反馈（对/错标记）→ 标注数据积累 → 模型 fine-tune → 分析精度提升 → 更好体验 → 更多用户上传。这是产品的核心壁垒。
