## 1 文档定位与使用指南

```

    ↓ 细化

1. **编码前**：阅读目标 Sprint 的「设计文档引用」段落，理解架构/DB/API/模块设计的约束

4. **跨 Sprint**：参照「§6 跨模块级联链」确保级联触发正确

```
app/
├── core/                  # 核心依赖
│   ├── deps.py            # get_current_user / get_admin_user / get_db / get_redis

├── utils/                 # 工具函数

tests/
