### 2.3 编码规范红线（CI 阻塞，违反即 PR 拒绝）

1. **禁止 class 组件**——全部函数组件 + Hooks
2. **禁止硬编码颜色/字号/阴影/圆角**——一律 CSS 变量（`var(--color-*)` / `var(--fs-*)` / `var(--shadow-card)` / `var(--radius-*)`）；字号仅允许 6 级规范值（12/13/15/18/24/32px）
3. **禁止硬编码中文文本**——全部 `t('key')`，且 key 必须同时存在于 zh-CN 与 en-US
4. **加载态用 NutUI `<Skeleton>`、空态用 `<Empty>`、表单弹窗用 `Popup`**（CP-006/008）
5. **每个 `frontend/src/services/*.ts` 函数名与路径必须与 backend.md / API 设计逐字一致**——前端 Service 是后端契约的镜像，发现不一致走契约修订流程，禁止前端私改路径
6. **类型契约**：请求/响应 TS interface 从后端 Pydantic Schema 镜像（字段名 snake_case 保持一致，RT-008 响应字段完整性由后端保证）
7. **WS 消息协议**：`{event, data}` 两级分发，先按 `event` 再按模块消费（R17 确认的统一协议）
8. **无障碍**：ARIA 五场景（Button/View-onClick/Input/SVG/lazy-load）+ WCAG AA（对比度 ≥4.5:1 / focus 可见 / 触摸目标 ≥24px / `aria-live="polite"`）

## 9. Anti-Hallucination 约束（前端专用）

1. **设计资产是唯一实现依据**：20 份设计文档（18 份切片 + 总览 + 界面设计）即规格；实现偏差要么修正代码要么走文档修订流程，禁止"文档归文档、代码归代码"
2. **API 路径/字段/错误码禁止臆造**：以 `app/api/v1/*/router.py` 实现 + backend.md 契约为准；后端未实现的端点前端禁止 mock 上线
3. **CSS 变量唯一定义**：`:root` 只在 `app.scss` 定义一次，模块 SCSS 只引用
4. **Tab Bar 配置唯一权威**：总览 §3.4 的 `app.config.ts`，禁止模块私自增删 Tab
