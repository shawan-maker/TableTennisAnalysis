### 13.2 错误码规范

- 400：请求参数错误（`文件大小与声明不符` / `未提供更新字段` / `分享不存在或已过期`）
- 401：未认证（`请重新登录` / `Token 已撤销` / `H5 Token 已过期`）
- 403：无权限（`您的账号正在注销中` / `管理员账号已禁用` / `需要超级管理员权限` / `此功能需要会员及以上等级`）
- 404：资源不存在（`报告不存在` / `用户不存在` / `比赛不存在` / `配置 {key} 不存在` / `训练方案不存在` / `训练单不存在`）
- 409：冲突（`您已提交注销申请` / `今日已打卡` / `比赛已开始或已结束` / `配置 {key} 已存在` / `训练单已完成`）
- 422：业务校验失败（`会员等级或周期参数不合法` / `比分不符合赛制规则` / `超过 7 天的订单不可退款`）
- 429：限流（`验证码已发送，1 分钟后重试` / `今日免费分析次数已用完` / `本月已导出过，请下月再试`）
- 502：外部服务异常（`微信登录服务暂时不可用` / `支付服务暂时不可用` / `退款服务暂时不可用`）
- 503：服务不可用（`AI 推理服务暂时不可用（熔断中）` / `Ball detection model not loaded`）
- 504：超时（`Ball detection timeout` / `Pose estimation timeout`）

**结论**：错误码语义清晰，4xx 与 5xx 边界明确，便于前端统一处理。
