## 三、P1 问题（高优先级）

### P1-1：硬编码 rgba 主色值 `rgba(230, 57, 70, ...)` 出现在 JS 逻辑中

- **文件+行号**：
  - `06-data_dashboard/frontend.md` L739：`if (maxVal === 0) return 'rgba(230, 57, 70, 0)'`
  - `06-data_dashboard/frontend.md` L741：``return `rgba(230, 57, 70, ${0.15 + intensity * 0.85})` ``
  - `03-video_analysis/frontend.md` L767：``return `rgba(230, 57, 70, ${alpha})` ``
- **问题描述**：热力图和视频分析时间轴中直接硬编码了主色的 RGB 值 `rgba(230, 57, 70, ...)`（即 #E63946），未通过 CSS 变量获取。第五轮修复已将 CSS 中的 rgba 替换为 color-mix，但 JS 逻辑中的动态色值计算遗漏。
- **修复建议**：方案 A：定义 `--color-primary-rgb: 230, 57, 70` CSS 变量，JS 中通过 `getComputedStyle` 读取；方案 B：在常量文件中定义 `PRIMARY_RGB = '230, 57, 70'` 统一引用。

### P1-2：硬编码 rgba 主色值 `rgba(230, 57, 70, 0.06)` 在 settings.md CSS 中

- **文件+行号**：`14-tab-pages/settings.md` L413
- **问题描述**：`.deletion-cooling-banner` 的 background 直接使用 `rgba(230, 57, 70, 0.06)` 硬编码主色透明度，未使用 CSS 变量。第五轮批量修复了 6 个文件的 CSS rgba，但 settings.md 是第八轮新增文件，未被覆盖。
- **修复建议**：改为 `background: color-mix(in srgb, var(--color-primary) 6%, transparent);` 或定义 `--color-primary-alpha-06` 变量。

### P1-3：新增间距变量 `--spacing-sm-md` / `--spacing-xl` / `--spacing-2xl` 零使用

- **文件+行号**：
  - `00-垂直切片设计总览.md` L132/L135/L136：三个变量已定义
  - 全部 13 个 frontend.md + 5 个 tab-pages：**0 处引用**
- **问题描述**：第八轮在 `:root` 中新增了 `--spacing-sm-md: 12px`、`--spacing-xl: 32px`、`--spacing-2xl: 48px` 三个变量，但所有前端切片中没有任何一处使用这些变量。对应的 12px/32px/48px 间距值仍以硬编码形式存在。
- **修复建议**：推迟至开发阶段批量替换（与第八轮决策一致）。但需确认开发团队知晓这三个变量的存在和用途。当前硬编码间距值统计：
  - frontend.md 文件：194 处
  - tab-pages 文件：3 处
  - **合计：197 处硬编码间距值**

### P1-4：Picker 组件导入源不一致

## 四、P2 问题（中优先级）

### P2-1：硬编码白色半透明值 `rgba(255, 255, 255, ...)` 在深色背景上

- **文件+行号**：
  - `00-home/frontend.md` L803：`border: 2px solid rgba(255, 255, 255, 0.3)` （头像边框，深蓝背景上）
  - `00-home/frontend.md` L824：`color: rgba(255, 255, 255, 0.6)` （次要文字，深蓝背景上）
  - `06-data_dashboard/frontend.md` L1129：`color: rgba(255, 255, 255, 0.8)` （热力图标签文字，彩色背景上）
  - `14-tab-pages/onboarding.md` L768：`color: rgba(255, 255, 255, 0.7)` （引导页遮罩文字）
- **问题描述**：在深色/彩色背景上使用半透明白色文字和边框时，直接硬编码 `rgba(255, 255, 255, ...)` 而非使用 `var(--color-text-inverse)` 配合 opacity 或 color-mix。设计系统已定义 `--color-text-inverse: #FFFFFF`，但不支持透明度调整。
- **修复建议**：定义 `--color-text-inverse-secondary: rgba(255, 255, 255, 0.6)` 和 `--color-text-inverse-tertiary: rgba(255, 255, 255, 0.3)` 变量；或使用 `color-mix(in srgb, var(--color-text-inverse) 60%, transparent)`。

### P2-2：非标准 text-shadow 值

- **文件+行号**：
  - `06-data_dashboard/frontend.md` L1124：`text-shadow: 0 1px 2px rgba(0, 0, 0, 0.3);`
  - `06-data_dashboard/frontend.md` L1130：`text-shadow: 0 1px 2px rgba(0, 0, 0, 0.3);`
- **问题描述**：热力图单元格内的文字使用了 `text-shadow: 0 1px 2px rgba(0, 0, 0, 0.3)` 文字阴影，设计系统仅定义了 box-shadow 规范 `0 2px 8px rgba(0,0,0,0.06)`，未定义 text-shadow 规范。
- **修复建议**：在设计系统中补充 text-shadow 规范（如需要保留可读性），或移除 text-shadow 改用 font-weight: bold 增强对比度。

### P2-3：硬编码 `rgba(0, 0, 0, 0.02)` 按压态背景

- **文件+行号**：`14-tab-pages/settings.md` L401
- **问题描述**：`.settings-cell:active` 使用 `background: rgba(0, 0, 0, 0.02)` 作为按压态背景，未使用 CSS 变量。
- **修复建议**：定义 `--color-press-overlay: rgba(0, 0, 0, 0.02)` 全局变量，或使用 `color-mix(in srgb, var(--color-text-primary) 2%, transparent)`。

### P2-4：`#E76F51` 警告色在文档注释中与设计系统不一致

- **文件+行号**：
  - `04-scoring/frontend.md` L1405：`警告色 #E76F51（失败）`
  - `05-match_data/frontend.md` L1299：`警告色 #E76F51（负）`
  - `前端切片8维度一致性审查报告.md` L66：`警告色 #E76F51`
- **问题描述**：设计系统定义 `--color-warning: #F4A261`（与 --color-accent 一致），但以上 3 处文档/注释引用了 `#E76F51` 作为警告色。实际 CSS 代码正确使用了 `var(--color-warning)`（已验证 10 处），但注释中的色值引用会导致开发人员误解。
- **修复建议**：将注释中的 `#E76F51` 统一修正为 `#F4A261` 或直接引用 `var(--color-warning)`。

### P2-5：`var(--color-text-inverse, #fff)` 包含 hex fallback

- **文件+行号**：
  - `11-payment/frontend.md` L314：`color: 'var(--color-text-inverse, #fff)'`
  - `11-payment/frontend.md` L441：`color: 'var(--color-text-inverse, #fff)'`
- **问题描述**：内联样式中使用 CSS 变量但带有 `#fff` hex fallback。虽然这是 CSS 变量的标准 fallback 用法，但与"禁止硬编码颜色值"的约束存在表述冲突。
- **修复建议**：可接受作为渐进增强 fallback 保留，或在全局确保 `--color-text-inverse` 一定被定义后移除 fallback。标记为低优先级。

### P2-6：video_analysis 底部固定栏使用负向 box-shadow

- **文件+行号**：`03-video_analysis/frontend.md` L1587
- **问题描述**：`box-shadow: 0 -2px 8px rgba(0, 0, 0, 0.06)` 用于 `.feedback-bar`（fixed 定位的底部反馈栏），Y 偏移为负值（向上投射阴影）。设计系统规范为 `0 2px 8px rgba(0,0,0,0.06)`（向下投射）。
- **修复建议**：此为底部固定元素的合理变体（阴影向上投射符合视觉逻辑），建议在设计系统中补充说明"底部固定元素允许使用 `0 -2px 8px rgba(0,0,0,0.06)`"。
