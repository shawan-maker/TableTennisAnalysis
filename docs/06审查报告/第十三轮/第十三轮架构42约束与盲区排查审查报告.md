## 新发现问题

### P2-1：日志轮转配置未落地到 docker-compose（R12-P2-12 修复不完整）

| 项目 | 内容 |
|------|------|
| **优先级** | **P2** |
| **问题描述** | 第十二轮 R12-P2-12 修复仅在 `docker.md` 的 `.env.example` 段（L850-856）添加了注释块描述 Docker 日志轮转配置（`# logging:` / `# driver: json-file` / `# max-size: "10m"` / `# max-file: "3"`），但**未在 `docker-compose.yml` 和 `docker-compose.prod.yml` 的任何服务定义中添加实际的 `logging:` 配置块**。grep `^\s+logging:` 在 docker.md 全文中 0 匹配，确认无实际配置。 |
| **影响范围** | 生产环境 Docker 容器使用默认 `json-file` 驱动且无大小限制，应用日志+Nginx 日志长期积累将填满磁盘，可能导致服务崩溃。开发环境无影响。 |
| **验证方法** | `grep '^\s+logging:' docker.md` → 0 匹配；`grep 'max-size' docker.md` → 仅 L855 注释行 |
| **修复建议** | 在 `docker-compose.prod.yml` 的 `app`、`celery-worker`、`celery-beat`、`gpu-service`、`nginx` 服务中各添加：<br>```yaml<br>logging:<br>  driver: json-file<br>  options:<br>    max-size: "50m"<br>    max-file: "3"<br>```<br>开发环境 `docker-compose.yml` 可选添加（开发环境日志量小）。同时删除 `.env.example` 中的注释块或将其改为实际配置说明。 |
