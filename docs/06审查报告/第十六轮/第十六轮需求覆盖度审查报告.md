## 3. 新发现问题

### P1-1：首页聚合前端引用不存在的端点 GET /dashboard/latest-advice-summary 🔴

**文件**：`06垂直模块前后端切片设计/00-home/frontend.md` L17, L105

**问题描述**：
00-home/frontend.md L105 调用 `request.get('/dashboard/latest-advice-summary')` 作为独立端点获取训练提醒摘要。但该端点在架构 §5.7 dashboard 模块表中不存在（仅有 overview/win-rate-trend/technique-stats/landing-heatmap/match-records 5 个端点）。

实际情况：`latest_advice_summary` 是 `GET /dashboard/overview` 响应体中的一个**字段**（API 设计 §6.1 L1779-1784），而非独立端点。data_dashboard 后端 L409/L419 已将该字段嵌入 overview 响应中返回。data_dashboard 前端 L42/L482-487 正确地从 overview 响应中读取 `data.latest_advice_summary`。

**影响**：若按 00-home/frontend.md 设计实现，首页训练提醒区域会调用不存在的端点，返回 404，导致该区域降级显示骨架屏。

**修复建议**：删除 00-home/frontend.md L87-106 中 `getLatestAdviceSummary()` 独立请求函数，改为从 `getOverview()` 返回值中读取 `latest_advice_summary` 字段。同步更新 L17 API 契约引用。

### P1-3：首页聚合端点清单三文档不一致 🔴

**涉及文件**：
- 架构 §5.7 L957-959（首页聚合段）

|------|-----------|

| 00-home/frontend.md L87-112 | users/profile, dashboard/overview, **gamification/checkin-calendar**, video-analysis/reports, **dashboard/latest-advice-summary**, **notifications/unread-count** |

三份文档列出了完全不同的端点组合，且各自包含不存在或错误的端点：
- 架构引用不存在的 `GET /training/calendar`（实际应为 `GET /gamification/checkin-calendar`）
