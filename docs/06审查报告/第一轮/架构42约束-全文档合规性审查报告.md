### P1-1：约束 #17 — 视频转码分辨率 720p vs 1080p

| 属性 | 值 |
|------|-----|
| **约束编号** | #17 |
| **约束原文** | AI 分析输入必须标准化为 1080p/30fps/H.264；多清晰度输出与 AI 分析并行 |
| **优先级** | **P1** |
| **违规文件** | `docs/04详细设计/03-模块详细设计.md` |
| **违规位置** | §3.2 AI 流水线模块，10 步流水线详细规格表，第 1348 行 |

| **正确值** | `标准化帧序列 (fps=30, 1080p)` |
| **影响** | 模块详细设计是开发实现的直接依据。Step 1 写 720p 将导致开发者按 720p 标准化视频，降低球体检测精度（架构 §6.3 明确 1080p 才能保证球体在画面中占 10-30 像素的可检测范围） |
| **修复建议** | 将模块详细设计 §3.2 第 1348 行的"720p"改为"1080p"，与架构 §6.1 和 ai_pipeline 切片保持一致 |
| **关联修复** | ai_pipeline 切片已修复（原 720p → 现 1080p），但模块详细设计未同步 |

**交叉验证**：
- 架构 §6.1 L1098: "标准化帧序列 (30fps, 1080p)" ✅
- 架构 §6.3 L1206: "分辨率 1920×1080 (1080p)" ✅
- ai_pipeline 切片 L25: "标准化帧序列 (fps=30, 1080p)" ✅（已修复）
- ai_pipeline 切片 L385-391: `"""Step 1: 视频预处理——标准化帧序列 (fps=30, 1080p)。"""` + `"resolution": "1080p"` ✅（已修复）
- 实施计划 L59: "FFmpeg 1080p/30fps" ✅
- **模块详细设计 L1348: "720p" ❌（未修复）**
