## 二、违规项详情

### A-1：slowapi 限流未在路由切片中实现 ❌

**架构要求**（§11.2 安全架构）：
- 全局默认 100 req/min
- AI 分析创建 10 req/hour（按 user_id）
- ALL API 端点必须配置 `@limiter.limit()`

**切片实际状态**：
- `00-垂直切片设计总览.md` §3.5（L207-214）提供了配置代码和限流规则表
- 但代码以注释形式存在：`# @limiter.limit("100/minute")`、`# @limiter.limit("10/hour", ...)`
- L214 明确写道："切片中各模块路由需补充 `@limiter.limit()` 装饰器"
- **grep 验证**：全部切片 .md 文件中 `@limiter.limit` 仅出现在总览注释中，0 个路由切片文件实际添加

**影响范围**：全部 13 个后端路由模块均未实现限流  
**修复建议**：在各模块 `§4 API 路由` 代码块中，为每个路由函数添加 `@limiter.limit()` 装饰器
