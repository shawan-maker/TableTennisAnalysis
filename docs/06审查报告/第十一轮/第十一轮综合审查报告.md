## P0 级发现（2 项）

### P0-1：APIRouter prefix 双重叠加（全部 13 个后端切片，96 个端点）

- **维度**：API 端点级
- **问题描述**：全部 13 个后端切片均同时声明 `APIRouter(prefix="/xxx")` 和 `include_router(router, prefix="/xxx")`。FastAPI 中 `include_router(prefix=X)` 会叠加到 `APIRouter` 已有 prefix 上，导致最终路由为 `/api/v1/xxx/xxx/endpoint` 而非 `/api/v1/xxx/endpoint`。
- **涉及文档**：

| 切片 | APIRouter prefix | include_router prefix | 错误路径示例 |
|------|-----------------|----------------------|-------------|
| 01-auth | `/auth` (L585) | `/auth` (L685) | `/api/v1/auth/auth/wechat-login` |
| 02-user | `/users` (L761) | `/users` (L863) | `/api/v1/users/users/profile` |
| 03-video_analysis | `/video-analysis` (L1070) | `/video-analysis` (L1207) | `/api/v1/video-analysis/video-analysis/upload-token` |
| 04-scoring | `/scoring` (L1115) | `/scoring` (L1230) | `/api/v1/scoring/scoring/matches` |
| 05-match_data | `/match-data` (L894) | `/match-data` (L947) | `/api/v1/match-data/match-data/records` |
| 06-data_dashboard | `/dashboard` (L779) | `/dashboard` (L830) | `/api/v1/dashboard/dashboard/overview` |
| 07-training_advice | `/training` (L1169) | `/training` (L1263) | `/api/v1/training/training/advice/{id}` |
| 08-progress_analysis | `/progress` (L1369) | `/progress` (L1443) | `/api/v1/progress/progress/snapshots` |
| 09-gamification | `/gamification` (L1033) | `/gamification` (L1092) | `/api/v1/gamification/gamification/points` |
| 10-membership | `/membership` (L794) | `/membership` (L833) | `/api/v1/membership/membership/tiers` |
| 11-payment | `/payment` (L1332) | `/payment` (L1432) | `/api/v1/payment/payment/orders` |
| 12-notification | `/notification` (L656) | `/notification` (L707) | `/api/v1/notification/notification/list` |
| 13-admin | `/admin` (L868) | `/admin` (L1071) | `/api/v1/admin/admin/login` |

- **修复建议**：统一采用以下模式之一（推荐方案 A）：
  - **方案 A**：`APIRouter(prefix="/xxx")` 保留，`include_router(router)` 移除 prefix 参数
  - **方案 B**：`APIRouter()` 移除 prefix 参数，`include_router(router, prefix="/xxx")` 保留

### P0-2：video_analysis 路由重复注册

- **维度**：API 端点级
- **问题描述**：`03-video_analysis/backend.md` 在 L1207 和 L1245 两处均有 `api_router.include_router(video_analysis_router, prefix="/video-analysis")`，同一路由注册两次。FastAPI 会抛出重复路由注册异常或产生冲突。
- **涉及文档**：`03-video_analysis/backend.md` L1207 + L1245
- **修复建议**：删除 L1245 的重复 `include_router` 调用，仅保留 L1207。
