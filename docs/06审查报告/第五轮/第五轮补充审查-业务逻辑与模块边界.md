## 二、新发现问题

### P2 级（4 项）

#### P2-NEW-1：API 11.1 GET /membership/tiers 响应缺 price_quarterly_cents

- 位置：API 详细设计 11.1 L2834-2867
- 现状：响应体每个 tier 对象包含 price_monthly_cents 和 price_yearly_cents 但缺 price_quarterly_cents
- 对比：DB 2.31 有 切片10 Model/TIER_SEEDS/TierBrief 有 API 缺
- 影响：前端无法从 API 获取季卡价格
- 修复建议：API 11.1 每个 tier 增加 price_quarterly_cents 字段

#### P2-NEW-2：DB 2.4 match 表 format 字段备注缺 bo1

- 位置：DB 详细设计 2.4 L607 + 5 L2383
- 现状：备注为 bo3/bo5/bo7/custom 缺 bo1
- 对比：切片04/05 Pydantic 前端 全部支持 bo1
- 修复建议：DB 2.4/5 备注改为 bo1/bo3/bo5/bo7/custom

#### P2-NEW-3：用户注销 72h 物理删除 Celery 任务未实现

- 位置：beat_schedule.py.md + 全部基础设施切片
- 现状：架构 11.4 定义 72h 删除 切片02 实现了 cancel-deletion 但无 permanent_delete_user 定时任务
- 影响：用户注销后 72h 到期个人信息不会被自动删除
- 修复建议：beat_schedule 新增 user.permanent_delete 任务 每日扫描 scheduled_deletion_at 到期用户

#### P2-NEW-4：操作日志 audit_log 6 个月自动清理未实现

- 位置：beat_schedule.py.md + admin.md
- 现状：架构 11.4 定义 6 个月清理 admin.md 实现 audit_log 表 但无清理任务
- 修复建议：beat_schedule 新增 admin.cleanup_audit_logs 任务 每月清理 6 个月前记录

### P3 级（2 项）

#### P3-NEW-1：DB 8.1 种子数据表头列名缺 _cents 后缀

- 位置：DB 详细设计 8.1 L2807
- 现状：表头 price_monthly/price_quarterly/price_yearly 但 DDL 2.31 列名为 price_monthly_cents 等
- 修复建议：8.1 表头加 _cents 后缀

#### P3-NEW-2：WebSocket score_update 事件字段名与 REST API 不一致

- 位置：API 1.9 L3355 vs API 5.3 L1477
- 现状：WebSocket 用 method REST 用 score_method
- 判定：可能有意紧凑设计 但与 REST 不统一
- 修复建议：统一为 score_method 或标注为例外
