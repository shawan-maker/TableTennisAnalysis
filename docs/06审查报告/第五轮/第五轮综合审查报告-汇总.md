## 二、P0 级问题（7 项 — 阻断性，必须立即修复）

### P0-1：gamification _auto_checkin streak_30 调用参数错位

- **文件**：`09-gamification/backend.md` L692-695
- **问题**：`_add_points("streak_30", user_id, db)` 使用位置参数，但方法签名是 `async def _add_points(db, user_id=, event_type=, ref_id=)`。第一个位置参数应为 `db`，实际传了 `"streak_30"`，运行时必崩。
- **影响**：连续打卡 30 天额外奖励无法触发，gamification 模块抛 TypeError
- **建议**：改为 `await GamificationService._add_points(db, user_id=user_id, event_type="streak_30")`

### P0-2：auth refresh_token 方法体被 consent 方法插入打断

- **文件**：`01-auth/backend.md` L427-506
- **问题**：`refresh_token` 方法的 `return RefreshResponse(...)` 脱离方法体，成为孤立代码。PIPL-001 consent 方法插入位置打断了原有方法结构，Python 导入时报 SyntaxError。
- **影响**：auth 模块完全无法加载，所有认证端点不可用
- **建议**：检查 L427-506 区域的方法缩进和结构，确保 refresh_token 方法体完整

### P0-3：03-video_analysis 路由前缀不匹配

- **文件**：`03-video_analysis/frontend.md` vs `00-垂直切片设计总览.md` app.config.ts
- **问题**：video_analysis 模块内部所有 `navigateTo` 使用 `pages/analysis/` 前缀，但 app.config.ts 注册的是 `pages/video-analysis/`。此外 processing 页在模块内叫 `progress`，在 app.config.ts 叫 `processing`。
- **影响**：视频分析模块所有内部导航运行时 404
- **建议**：批量将模块内 `pages/analysis/` 替换为 `pages/video-analysis/`，`progress` 替换为 `processing`

### P0-4：CI/CD Dockerfile 路径与 Docker 配置不匹配

- **文件**：`13-infrastructure/ci_cd.md` vs `13-infrastructure/docker.md`
- **问题**：CI/CD 流水线引用的 Dockerfile 路径与 Docker 配置中定义的不一致
- **影响**：CI 构建步骤找不到 Dockerfile，部署流水线失败
- **建议**：统一 Dockerfile 路径引用

### P0-5：Beat 时区注释与代码矛盾

- **文件**：`13-infrastructure/beat_schedule.py.md` L117-118
- **问题**：注释写"UTC 时区"但代码设 `beat_schedule_timezone = "Asia/Shanghai"`
- **影响**：定时任务执行时间与预期不符
- **建议**：统一为 UTC 或 Asia/Shanghai，注释与代码一致

### P0-6：GPU 健康检查间隔在两文档中矛盾

- **文件**：`13-infrastructure/docker.md` vs `13-infrastructure/ai_inference.md`
- **问题**：Docker 配置和 AI 推理服务文档对 GPU 健康检查间隔给出了不同的值
- **影响**：运维监控可能基于错误间隔配置告警
- **建议**：统一为 30s 或明确区分不同场景的检查间隔

### P0-7：scoring 调用未定义的 MatchDataService.create_record_from_scoring

- **文件**：`04-scoring/backend.md` L942 vs `05-match_data/backend.md`
- **问题**：scoring 模块调用 `MatchDataService.create_record_from_scoring`，但 match_data 切片未定义此方法
- **影响**：记分完成后无法自动创建比赛数据记录
- **建议**：在 match_data/backend.md 中补充 `create_record_from_scoring` 方法定义
