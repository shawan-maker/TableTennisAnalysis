## 四、已知限制

1. **WS 重连补偿测试超时**（5 个）：test_ws_channels.py::TestWSReconnectCompensation 的测试在测试环境中挂起，原因是 WebSocket 连接补偿机制需要实时 WS 服务支持。这是测试环境限制，非代码缺陷。

2. **全量测试超时**：conftest.py 每个 test function 重建 schema（DROP + CREATE SCHEMA），~3s/test。全量 335 个测试需 ~1005s，超出单次工具 300s 超时。建议后续优化 fixture scope 为 class/module 级别。

3. **model_activate 跳过**：test_admin.py::TestAdminPermission::test_model_activate 一直被 skip（需要 ML 模型激活环境）。
